# Границы реестра

Дата поиска: 16–17 ноября 2026. Территория: ЦАО, САО, СВАО. СЗАО и Московская область не включены.

Исходные каталоги: https://moscowpubs.ru/map/ и разделы «Пабы» по округам на https://edanyama.ru/ . Поиск дополнен официальными страницами Harat’s и The Libertines. Источник поиска указан в каждой записи sources.json; он не является источником цен.

100 — число адресов-кандидатов, а не число подтверждённых действующих пабов. Только записи с адаптерами проверены для автоматического получения цен. Большинство остальных требует уточнения формата, работы заведения и принадлежности сайта конкретному филиалу. Недоступный сайт не означает, что паб закрыт. Социальные страницы и площадки бронирования не используются для извлечения цен.

В отдельные записи выделены филиалы. Повторы между двумя каталогами объединены вручную по адресу. Из основной выборки исключены заведения, позиционирующиеся как рестораны другого формата: CAVINA, El Gaucho, Пилзнер, Козловна, Brunnen, Пражка, «В ус не дул», Spaten Haus, Krombacher Beer Kitchen, The Pivo, Экспромт. Это критерий отбора данного проекта, а не официальная классификация заведений.

Не включены: «Бибирево» на Украинском бульваре (ЗАО), пабы Щукино (СЗАО), заведения Мытищ. Название паба или ближайшая станция метро не определяют административный округ.

Список не является исчерпывающим: каталоги неполны и иногда содержат закрытые точки. Добавление записи без официального меню не создаёт фиктивных цен. Для полного охвата нужна дальнейшая проверка кандидатов и адаптеры PDF/изображений/индивидуальных сайтов.


## Аудит подключения 17–18 ноября 2026

Файлы COVERAGE_AUDIT.csv и coverage_audit.json содержат 200 строк: по две категории для каждого адреса.
В sources.json те же результаты находятся в coverage.food и coverage.beer.
Значение «Нужна доработка» честно обозначает невыполненную часть подключения: меню найдено, но адаптер ещё не готов.
HTTP 503, 402, 404, таймаут и заглушка Site Unavailable — результаты конкретных попыток из среды проверки;
они не доказывают недоступность для каждого посетителя и не подтверждают закрытие заведения.
У Brasserie 0.33 официальный внешний каталог 033.rest запрещает автоматический сбор через robots.txt.
Сборщик сохраняет это ограничение. Цены из каталога не включены в сбор.
Для OldSchool на Китай-городе сайт указывает другой адрес; меню доставки Изи Паб и тарифы БирХаус
также требуют отдельной проверки условий. Это не обычные цены меню конкретного зала.
