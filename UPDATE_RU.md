# Обновление до версии 2.2

1. Остановите дэшборд и сборщик, сохраните резервную копию проекта.
2. Скопируйте содержимое папки `pub_price_monitor` из ZIP в существующую папку проекта.
3. Сохраните свои `data`, `.env` и `.venv`: в ZIP их нет. Пользовательские изменения `sources.json` перенесите из резервной копии.
4. Установите обновлённые зависимости из терминала PyCharm:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Добавлена библиотека `pypdf==5.1.0`. Python остаётся 3.10. Можно повторно запустить `setup_windows.bat`.

5. Запустите `start_dashboard.bat`, затем «Источники → Проверить цены сейчас».
6. Во вкладке «Все пабы» смотрите отдельные статусы и причины по горячим блюдам и пиву. Таблица выгружается в CSV.

В версии 2.2 подключено 21 заведение (ранее 11), 35 меню. Полное подключение всех 100 адресов не завершено.
Для недоступных сайтов, неподтверждённых адресов и ещё не реализованных адаптеров указаны разные причины.
Отсутствующая цена не заменяется нулём; история сохраняется. Архив не содержит готовой базы наблюдений.
Подключённый адаптер не гарантирует доступность сайта в момент следующего запуска.
