# Загрузчики PDF, графических и динамических меню

Базовый проект (`requirements.txt`) работает без браузера, Tesseract и GPU.

## Установка на Windows / PyCharm

PDF с текстовым слоем читаются через `pypdf`, уже включённый в базовые зависимости.

Для сканированных PDF и PNG/JPEG/WebP:
```powershell
python -m pip install -r requirements-ocr.txt
```
Дополнительно установите **Tesseract OCR** как системную программу и языковые данные `rus` и `eng`. Библиотека `pytesseract` сама бинарный Tesseract не устанавливает. При необходимости укажите путь к `tesseract.exe` через настройки системы PATH.

Для динамических HTML-меню:
```powershell
python -m pip install -r requirements-browser.txt
python -m playwright install chromium
```
Это необязательные зависимости; ни Ollama, ни платный LLM для этих адаптеров не нужны.

## Форматы sources.json

**Проверяемый PDF с текстовым слоем** (секции и названия — строго из конкретного меню):
```json
{
  "id": "sample_pdf_food", "url": "https://official.example/menu.pdf",
  "kind": "food", "parser": "document", "format": "pdf",
  "sections": ["ГОРЯЧИЕ БЛЮДА"], "stop_sections": ["ЗАКУСКИ", "ДЕСЕРТЫ"],
  "min_items": 5, "max_pages": 8, "allow_ocr": false
}
```
Если PDF — скан, включите `allow_ocr: true` только после проверки исходного документа. Для картинки укажите `format: "image"` и точную ссылку на PNG/JPEG/WebP; OCR применяется автоматически. Никакие ссылки на примеры не активированы в проекте.

**Динамический HTML** (CSS-селекторы — только после исследования конкретного сайта):
```json
{
  "id": "sample_dynamic_food", "url": "https://official.example/menu",
  "kind": "food", "parser": "structured_html", "format": "browser",
  "wait_selector": ".menu-card", "min_rendered_chars": 60,
  "selectors": {
    "card": ".menu-card", "name": ".dish-name",
    "price": ".dish-price", "section": ".dish-category",
    "portion": ".dish-weight"
  },
  "sections": ["Горячие блюда"], "min_items": 5
}
```

Браузер разрешает запросы только к явно доверенным HTTPS-доменам и предварительно проверяет `robots.txt`. Сторонние домены заблокированы по умолчанию. Если сайт использует API на другом домене, его следует отдельно проверить и добавить в `browser_hosts` **и** реестр разрешённых хостов. Перенаправления за пределы проверенной конфигурации не допускаются.

## Контроль качества

- Не допускается собирать неопределённую цену, не соответствующую указанной порции, или смешивать разделы кухни и напитков.
- Парсер требует заранее перечисленных категорий и `min_items`; отсутствие раздела вызывает ошибку.
- Все OCR-извлечения получают статус `partial` с уведомлением о ручной проверке. Они **не публикуются как полный подтверждённый снимок**.
- Библиотека не обходит robots.txt, капчи и ограничения доступа. Если сайт запрещает запросы либо не публикует цены, это не успешное подключение.
- Снимки и контрольные SHA-256 сохраняются в `data/snapshots/`; самостоятельно не редактируйте исходные доказательства.
- Для серий с частичным статусом действующий код `current_rows()` использует последнее подтверждённое наблюдение при его наличии и не заменяет его непроверенным OCR.
- Локально проверить все тесты: `python -m pytest -q`. Парсеры на примерах/фикстурах не означают, что конкретный паб подтверждён реальным запросом.

## Ручное подтверждение OCR-цен

После сбора со статусом `review` откройте вкладку «Источники» и узнайте источник, либо найдите ID проверки в таблице `checks` локальной SQLite. Исходный PDF/PNG и контрольные SHA-256 находятся в папке снимка (`data/snapshots`), указанной в результатах.

Сначала получите список позиций и исходное доказательство:
```powershell
python -m monitor.cli review --check-id 123
```

**Только после сверки всех позиций по оригинальному меню** (названия, цены, объёмы, действительность филиала и дата меню) можно подтвердить:
```powershell
python -m monitor.cli approve --check-id 123 --approver "Редактор" --confirm-reviewed
```
Это сознательное локальное действие. Оно меняет статус именно OCR-снимка на `ok`, а отдельная таблица `approvals` хранит, кто и когда подтвердил данные. Без подтверждения OCR не участвует в текущих ценах и сравнении.

## Почему не включено автоматически 82 оставшихся заведения

Каждому требуется индивидуально подтверждённый официальный URL, соответствие филиалу, список заголовков и/или CSS-селекторов, а также успешный живой запуск. Общий механизм не может правдоподобно восстановить отсутствующие или закрытые для доступа цены. Поэтому в `sources.json` массовые фиктивные источники не создаются.
